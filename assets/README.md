# Assets

- `vo/`: narration, one Ogg Opus clip per voiced line (161 files, 2.7 MB). Generated by `tools/vo_build.mjs`. See [../docs/VOICEOVER.md](../docs/VOICEOVER.md).
- `sfx/`: recorded answer feedback, `correct.mp3` and `incorrect.mp3`, played by `js/core/audio.js`.
- `start/`: first-screen art. `thumbnail.jpg` (1920×1080) and `start-button.webp` are web-sized copies of `thumbnail0001.png` and `startbutton 000.png` in the project root (346 KB instead of about 3 MB).
